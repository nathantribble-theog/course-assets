# course-assets

Public image hosting for course slide decks built in Gamma. Gamma embeds these images by their `raw.githubusercontent.com` links, so **this repo must stay public** or the images will break in the decks.

## marketing-101/
- `images/`: original visuals from the Beautiful.ai "Marketing 101" deck, used in the Gamma version (https://gamma.app/docs/cn292uqyp7mgkc1). The original slide 9–11 graphics (`09-`, `10-`, `11-`) are archived here but were replaced in the Gamma deck with new visuals.
- `gamma-input.md`: the slide-by-slide source text and speaker notes sent to Gamma.
